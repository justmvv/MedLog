# Журнал изменений

Версии следуют [семантическому версионированию](https://semver.org/lang/ru/) и полю
`version:` в `pubspec.yaml`. Номер сборки — номер запуска GitHub Actions, который
её опубликовал. Текущая версия видна внизу экрана «Схема».

## [Не выпущено]

- Тепловая карта: сегодняшний день, пока впереди есть приёмы, больше не
  заливается как «всё принято» — клетка показывает долю принятых за весь день
  и счётчик вида «2/4»; в «дней без пропусков» он попадает только после
  последнего приёма.
- Превью ссылки в мессенджерах: название MedLog, описание и иконка (Open Graph).

## [1.1.0] — 2026-10-12

Приложение сосредоточено только на приёме лекарств.

- Приложение переименовано из «Крест» в MedLog.
- Удалено: учёт еды — отметка времени приёма пищи, состав блюд, справочник
  калорий и свои продукты; режим «Калории» на тепловой карте.
- В итогах месяца вместо средних калорий — среднее отклонение фактического
  времени приёма от планового.
- В деталях дня — сколько приёмов пропущено и отклонение от плана в минутах;
  хронология показывает только лекарства.
- Ранее сохранённые записи о еде не удаляются из хранилища устройства, но
  больше не отображаются.

## [1.0.0] — 2026-10-07

Первый выпуск.

- Схема приёма лекарств: название, доза, заметка, примерное время (готовые
  варианты «1/2/3 раза» или своё). Изменение времени не переписывает прошлые
  дни; «Завершить» убирает лекарство из ежедневного списка, сохраняя историю.
- Экран «Сегодня»: отметка приёма галочкой с фактическим временем, правка
  времени, пометка «пропущено?» через час после планового времени, прогресс дня.
- Еда: фиксация времени приёма пищи, состав с граммами и калориями из
  локального справочника (≈140 продуктов), свои продукты, «Часто».
- Тепловая карта месяца в двух режимах — «Приём лекарств» и «Калории»,
  итоги месяца; детали дня — общая хронология лекарств и еды.
- PWA: установка (Chrome/Edge/Android, подсказка для iOS), полная работа
  офлайн с первого визита, обновление по плашке «Доступна версия …».
- Палитра и гранёная иконка-крест в стиле calorie_cam.
